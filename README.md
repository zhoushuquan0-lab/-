# Brand Content Engine MVP V1.0

小红书品牌内容决策与生产系统 MVP。

## 运行方式

```bash
cd brand-content-engine
pnpm install
pnpm dev
```

打开：

```text
http://localhost:5173/
```

## 数据维护

所有静态数据在：

```text
src/data.js
```

后续可以替换为真实 AI 接口或真实内容数据。

## 页面模块

- 首页 Dashboard：今日内容机会判断
- 内容决策页：品牌、产品、目标、内容方向评分
- 选题生成页：20 个小红书选题
- 内容生成页：笔记标题、正文、封面、拍摄建议、标签
- 内容资产库：已生成内容沉淀
- 数据复盘页：发布数据和 AI 复盘建议

## 后续可扩展

- 接入小红书热点数据
- 接入品牌搜索数据
- 接入真实 AI 选题和笔记生成
- 接入内容发布后数据回流
